# CyberPW Assistant — офіційний реліз

Цей публічний репозиторій містить лише готовий інсталятор CyberPW Assistant. Вихідний код застосунку зберігається приватно й тут не публікується.

## Завантаження

[**Завантажити актуальну версію**](https://github.com/vitalikjukivskiy/cyberpw-assistant-releases/releases/latest)

У релізі використовуйте тільки файл `CyberPW-Assistant-Setup.exe`. Він встановлює або оновлює Assistant у власній папці та зберігає локальні профілі й налаштування користувача.

GitHub автоматично показує архіви Source code для тегу; вони містять лише цей README, а не код CyberPW Assistant.
