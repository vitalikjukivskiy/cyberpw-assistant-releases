# CyberPW Assistant — публічні релізи

Цей репозиторій містить готовий інсталятор CyberPW Assistant. Вихідний код застосунку зберігається приватно й тут не публікується.

## Завантаження

Актуальний опублікований реліз на **08.10.2026 — 2.0.82-beta**, від 07.10.2026. Це **beta / prerelease**.

[**Завантажити CyberPW-Assistant-Setup.exe · 2.0.82-beta**](https://github.com/vitalikjukivskiy/cyberpw-assistant-releases/releases/download/v2.0.82-beta/CyberPW-Assistant-Setup.exe)

[Опис 2.0.82-beta та межі перевірки](https://github.com/vitalikjukivskiy/cyberpw-assistant-releases/releases/tag/v2.0.82-beta) · [Усі релізи](https://github.com/vitalikjukivskiy/cyberpw-assistant-releases/releases)

GitHub `/releases/latest` зараз вибирає старішу 2.0.76, оскільки нові версії позначені prerelease. Посилання вище веде безпосередньо на 2.0.82-beta. Статуси релізів і бінарні файли не змінювалися.

Закрийте Assistant і запустіть інсталятор. Він встановлює або оновлює програму у власній папці зі збереженням локальних профілів і налаштувань. Гра й Assistant мають працювати з однаковими правами Windows. Після перезапуску гри повторно виберіть вікна паті й синхронізуйте потрібного персонажа для титулів.

**Живі дії на клієнті від 07.10.2026 ще не підтверджені:** Windows відмовив у читанні процесу гри. Перевірка файла клієнта й автоматизовані сценарії не підтверджують виконання паті-дій, міток, навичок, підбору, заміни спорядження, комісійки або циклу Чон/Пон на персонажі. Безперервні 15 квестів наживо не підтверджені; Oracle залишається зовнішнім DRY-RUN preview.

## Можливості та демонстрації

- **Паті-дії:** слідування за ПЛ, асист, макроси 1–3, збір і повний розпуск паті, власні бінди й повернення фокуса. Розпуск охоплює всю паті вибраного ПЛ, включно з непозначеними та віддаленими учасниками. Кнопка макросу запускає його один раз за натискання. [Демонстрація від 05.10.2026](https://www.youtube.com/watch?v=hTDhvLA6LiM).
- **Нові розділи:** VIP-лялька з імпортом спорядження, заточки й каменів; Auto Чон-Пон; поширення й експорт інвентарю та складів; дошка оголошень і пошук паті. [«CyberPW Assistant update 2.72» від 27.09.2026](https://www.youtube.com/watch?v=QXTomqLBf7k). Актуальні VIP-тарифи та умови перевіряйте у програмі.
- Друзі та клан у відео названі майбутніми розділами. Повний розрахунок характеристик ляльки й онлайн-обмін тут не обіцяються без окремого підтвердження.

Ці відео демонструють попередні збірки й не підтверджують сумісність клієнта від 07.10.2026.
