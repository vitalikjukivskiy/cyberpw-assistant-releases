# CyberPW Assistant — безкоштовно для всіх

Цей репозиторій містить готовий інсталятор CyberPW Assistant. Вихідний код застосунку зберігається приватно.

## Сумісність із новим клієнтом

Версія 2.0.91 підтримує клієнт CyberPW від 28.10.2026: відновлено визначення персонажа, титули, журнал квестів, інвентар і деталі спорядження. Оновлено Чон-Пон, паті-дії, підбір предметів і профіль комісійки. Після оновлення перезапустіть хелпер і оновіть список вікон; перезапуск гри не потрібний.

## VIP без оплати

Хелпер повністю безкоштовний. VIP-доступ відкрито всім користувачам без оплати й без терміну дії. Купувати або продовжувати VIP більше не потрібно. Для онлайн-функцій увійдіть у свій особистий кабінет.

Незабаром на сервері заборонять пілот. Через це функціонал хелпера буде скорочено. Про конкретні зміни й дату їх увімкнення повідомимо окремо.

## Можливості та демонстрації

- **Паті-дії:** слідування за ПЛ, асист, макроси 1–3, збір і повний розпуск паті, власні бінди й повернення фокуса. Розпуск охоплює всю паті вибраного ПЛ, включно з непозначеними та віддаленими учасниками. Кнопка макросу запускає його один раз за натискання. [Демонстрація від 05.10.2026](https://www.youtube.com/watch?v=hTDhvLA6LiM).
- **Розділи хелпера:** лялька з імпортом спорядження, заточки й каменів; Auto Чон-Пон; поширення й експорт інвентарю та складів; дошка оголошень і пошук паті. [«CyberPW Assistant update 2.72» від 27.09.2026](https://www.youtube.com/watch?v=QXTomqLBf7k). VIP-функції тепер безкоштовні для всіх.
- Друзі та клан у відео названі майбутніми розділами. Повний розрахунок характеристик ляльки й онлайн-обмін потребують окремого підтвердження.

Відео демонструють попередні збірки. Живі дії в грі та сумісність із конкретним клієнтом потребують окремої перевірки. Безперервні 15 квестів наживо не підтверджені; Oracle залишається зовнішнім preview.
